# Распределенная система сбора данных на STM32F103C8T6
Система представляет собой **два микроконтроллера STM32F103C8T6**, взаимодействующих по интерфейсу **SPI**. Ведущий контроллер фиксирует нажатие пользователем одной из кнопок и отправляет запрос с кодом ведомому контроллеру. Тот в соответствии с кодом операции считывает значения **датчика температуры и влажности DHT11** либо **датчика расстояния HC-SR04**. Далее ведущий получает результаты измерения от ведомого. Результаты выводятся на **ЖК-дисплей** по интерфейсу **I2**C. На обоих устройствах использована ОС **FreeRTOS**, для взаимодейтсвия между задачами использованы **очереди** и **бинарные семафоры**.

### Распиновка ведущего (SPI master)
| Пин | Назначение                                                                          |
|-----|-------------------------------------------------------------------------------------|
| PA4 | SPI Chip select - Сигнал для выбора ведомого, с которым производится взаимодействие |
| PA5 | SPI Clock - Тактирование SPI                                                        |
| PA6 | SPI MISO - Линия передачи данных от ведомого к ведущему                             |
| PA7 | SPI MOSI - Линия передачи данных от ведущего к ведомому                             |
| PB3 | Подключение кнопки для запроса на чтение датчика температуры и влажности DHT11      |
| PB4 | Подключение кнопки для запроса на чтение датчика расстояния HC-SR04                 |
| PB6 | I2C SCL - Тактирование I2C                                                          |
| PB7 | I2C SDA - Передача данных с ЖК-дисплеем                                             |


### Распиновка ведомого (SPI slave)
| Пин | Назначение                                                                           |
|-----|--------------------------------------------------------------------------------------|
| PA4  | SPI Chip select - Сигнал для выбора ведомого, с которым производится взаимодействие |
| PA5  | SPI Clock - Тактирование SPI                                                        |
| PA6  | SPI MISO - Линия передачи данных от ведомого к ведущему                             |
| PA7  | SPI MOSI - Линия передачи данных от ведущего к ведомому                             |
| PA11 | Подключение к пину ECHO датчика HC-SR04. Принимает данных от датчика                |
| PB5  | Подключение к пину TRIG датчика HC-SR04. Передает датчику запрос на измерение       |
| PB9  | Подключение к пину данных датчика DHT11                                             |

# Иерархия проекта
- **/SPI_master** - проект ведущего МК
- **/SPI_slave** - проект ведомого МК
